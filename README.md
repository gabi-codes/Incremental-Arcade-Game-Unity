# Incremental Arcade Game (WIP)

A minimalistic 2D incremental arcade game built in Unity, focused on progression, gameplay, and expressive weapon mechanics.
The project explores scalable progression systems, physics-based combat, and clean visual presentation using minimalist, vector-inspired art combined with shaders and particle effects.

---

## Features

- Character progression with incremental, arcade-style scaling  
- Multiple weapon systems, each with unique mechanics and distinct gameplay behavior  
- Multiple enemy types with unique properties that influence combat and player strategy  
- Unlockable content and progression systems
- Light tower defense elements 
- Minimalist visual style created with custom shaders, particle systems, and engine-level effects
